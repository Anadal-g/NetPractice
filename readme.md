# NetPractice

## Description

NetPractice is a 42 networking project focused on learning the basics of TCP/IP networking.

The objective is to solve 10 networking exercises by correctly configuring:

* IP addresses
* Subnet masks
* Default gateways
* Routers and switches

This project helps understand how devices communicate inside and between networks.

---

## Instructions

### Run the interface

Inside the project folder run:

```bash
./run.sh
```

If it does not work:

```bash
python3 -m http.server 49242
```

Then open:

```text
http://localhost:49242
```

### Complete the levels

* Enter your 42 login.
* Solve the 10 levels.
* Use **Check again** to verify the configuration.
* Export each level using **Get my config**.

### Submission

The repository must contain:

* `README.md`
* 10 exported configuration files (one per level)
* All files placed at the root of the repository
